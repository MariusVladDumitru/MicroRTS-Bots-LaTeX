# Folder structure
- **code**: all LaTeX source code goes here.
  - **code/tex/**: project .tex files go here.
  - **code/images/**: images needed to compile .tex files from code/tex go here.
  - **code/pdf/**: final .pdf file(s) assembled from all the subfolders in code go here. [ Note: Don't know yet if i need this or not, probably will add it later if i need it]
- **out**: all intermediary compiled files and final compiled .pdf file go here. Not tracked by git. [ Note: i probably will move the final .pdf file somewhere else, but not sure yet].
- **docs**: all documentation goes here.
    - **docs/Notes/**: my Notes go here. Any Notes in LaTeX format will output intermediar and final compiled files in out.
    - **docs/Notes/tex/**: my .tex Notes files go here.
    - **docs/Notes/images/**: images needed to compile .tex files from docs/Notes/tex go here.
    - **docs/Notes/pdf/**: final .pdf Notes files go here. They are assemble from all the subfolders in docs/Notes.
- **template-archives/**: all LaTeX template archives go here. Please add the date in each archive name so that you know if you have the latest one or not.
