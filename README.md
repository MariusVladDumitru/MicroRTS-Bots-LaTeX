# Folder structure
- **code**: all LaTeX source code goes here.
- **out**: all intermediary compiled files and final compiled pdf file go here. Not tracked by git.
- **docs**: all documentation goes here.
    - **docs/Notes**: my Notes go here. Any Notes in LaTeX format will output intermediar and final compiled files in out.
- **template-archives**: all LaTeX template archives go here. Please add the date in each archive name so that you know if you have the latest one or not.
